# MERIDIAN Treasury (BRAT distribution mirror)

Prebuilt BRAT-install mirror for **MERIDIAN Treasury** — Obsidian-native
envelope/zero-based budgeting, double-entry accounts, and net worth; sync-safe
across iPhone and desktop; open, portable data; import only (no bank connection).

Source and history live in the `obsidian_workspace.obs` monorepo
(`plugins/treasury` + `packages/ledger`). This repo receives the prebuilt
`main.js` / `manifest.json` / `styles.css` and cuts a GitHub release per version
for BRAT.

**Install:** BRAT → *Add beta plugin* → `SilentNinja06/treasury_obs`.
